# IndiaByLocal

A marketplace where travellers from the US, UK, EU, Canada and Australia book licence-verified local guides and tours in India, at one all-in price.

**Status:** planning. No application code yet. The blueprint in `docs/` was produced from 13 parallel research tracks on 11 Nov 2026 and is the source of truth for what gets built and in what order.
